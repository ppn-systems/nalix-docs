**Namespace:** `Nalix.Abstractions.Networking.Packets`  
**Assembly:** `Nalix.Abstractions`

`PacketMetadata` is an immutable `readonly struct` that stores the compiled handler attributes for a `[PacketOpcode]` method. It is instantiated once at startup by `PacketHandlerGenerator` and exposed on `IPacketContext<TPacket>.Attributes`.

## Source Mapping

- `src/Nalix.Abstractions/Networking/Packets/PacketMetadata.cs`
- `analyzers/Nalix.Analyzers.Generators/PacketHandlerGenerator.cs`

## Compile-Time Generation

`PacketHandlerGenerator` inspects all attributes declared on each `[PacketOpcode]` method at compile time and constructs the `PacketMetadata` instance directly in `<Controller>_PacketController.g.cs`:

```csharp
// Generated by PacketHandlerGenerator:
PacketMetadata metadata = new(
    packetOpcode: new PacketOpcodeAttribute(0x3001),
    timeout: new PacketTimeoutAttribute(5000),
    permission: new PacketPermissionAttribute(PermissionLevel.USER, PermissionEvaluation.MinimumLevel),
    encryption: new PacketEncryptionAttribute(true, CipherSuiteType.Chacha20Poly1305),
    rateLimit: new PacketRateLimitAttribute(10, 3) { PolicyId = "chat-send" },
    transport: new PacketTransportAttribute(NetworkTransport.TCP),
    customAttributes: null);
```
