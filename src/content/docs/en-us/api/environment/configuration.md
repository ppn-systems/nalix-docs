**Namespace:** `Nalix.Environment.Configuration` (and `Nalix.Environment.Configuration.Binding`)  
**Assembly:** `Nalix.Environment`

The `Nalix.Environment` configuration system binds `.ini` files to strongly-typed `ConfigurationLoader` classes using compile-time code generated by `ConfigurationGenerator` (zero runtime reflection).

## `ConfigurationManager`

`ConfigurationManager` (`public sealed class ConfigurationManager : IDisposable`) manages the active `.ini` file (defaulting to `<Directories.ConfigurationDirectory>/default.ini`), debounced `FileSystemWatcher` reloads (`300ms`), and the thread-safe cache of `ConfigurationLoader` instances.

## `ConfigurationLoader`

All option classes inherit from `ConfigurationLoader` (`Clone<T>() where T : ConfigurationLoader, new()`) and must be declared `partial` so `ConfigurationGenerator` can emit `BindProperties`, `CopyPropertiesTo`, `CloneEmpty`, and `ValidateDataAnnotations`.

### Section Naming Convention

The `.ini` section name is derived by stripping standard suffixes (`Options`, `Config`, `Settings`, `Option`, `Configs`, `Setting`, `Configuration`, `Configurations`) from the class name:

- `NetworkSocketOptions` $\rightarrow$ `[NetworkSocket]`
- `TransportOptions` $\rightarrow$ `[Transport]`

### Supported Property Types (`IniConfig`)

`IniConfig` and `ConfigurationGenerator` support:
- **Integers & Bytes:** `byte`, `sbyte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong` (`GetByte`, `GetSByte`, `GetInt16`, `GetUInt16`, `GetInt32`, `GetUInt32`, `GetInt64`, `GetUInt64`)
- **Floating-Point & Decimal:** `float` (`GetSingle`), `double` (`GetDouble`), `decimal` (`GetDecimal`)
- **Primitives & Value Types:** `bool` (`GetBool`), `char` (`GetChar`), `string` (`GetString`), `TimeSpan` (`GetTimeSpan`), `DateTime` (`GetDateTime`), `Guid` (`GetGuid`), and `enum` (`GetEnum<TEnum>`).

```csharp
using Nalix.Abstractions;
using Nalix.Abstractions.Validation;
using Nalix.Environment.Configuration.Binding;

[IniComment("Server room settings")]
public sealed partial class ServerRoomOptions : ConfigurationLoader, IValidatableConfiguration
{
    [IniComment("Listen port (1..65535)")]
    [ValueRange(1, 65535)]
    public ushort Port { get; set; } = 57206;

    [ConfiguredIgnore]
    public string InternalRuntimeId { get; set; } = "local";

    public void Validate() => this.ValidateDataAnnotations();
}
```
